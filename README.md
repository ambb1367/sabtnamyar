# ثبت‌نام‌یار (SabtNamYar)

**ثبت‌نام‌یار** یک اپلیکیشن اندروید فارسی (راست‌به‌چپ) است که **ثبت‌نام‌های مهم ایران** را
قدم‌به‌قدم و به‌صورت تصویری توضیح می‌دهد.

> نسخه ۱٫۰٫۰ — سازگار با اندروید ۵٫۰ (API 21) و بالاتر

## قابلیت‌ها

- 🗂️ دسته‌بندی ثبت‌نام‌ها در موضوعات مختلف (هویت، بیمه، مالیات، خودرو، نظام وظیفه، گذرنامه، مسکن، آموزش، اشتغال، قضایی، خدمات شهری، کسب‌وکار، رفاه و سفر)
- 📋 هر ثبت‌نام شامل پیش‌نیازها، تعداد گام‌های مشخص و هر گام با عنوان، توضیح، نکته و تصویر کمک‌کننده
- ✅ وضعیت ثبت‌نام‌ها: **فعال**، **به‌زودی**، **پایان‌یافته** (برای آرشیو و مرجع)
- 🔄 **به‌روزرسانی خودکار**: با ضربه زدن روی دکمه «به‌روزرسانی»، برنامه فهرست تازه را از گیت‌هاب دریافت و ثبت‌نام‌های جدید را اضافه می‌کند
- 📥 سه لایه محتوا: فایل بذر همراه برنامه + نسخه کش‌شده محلی + فایل JSON در گیت‌هاب
- 🔍 جست‌وجو و فیلتر بر اساس دسته‌بندی و وضعیت
- 📤 اشتراک‌گذاری، کپی متن راهنما، باز کردن سامانه ثبت‌نام در مرورگر
- 🌓 پشتیبانی از حالت روشن/تاریک
- 💾 کاملاً آفلاین با داده بذر

## دریافت APK

فایل APK در بخش **Releases** همین مخزن قابل دریافت است. همچنین با هر بار اجرای گردش‌کار، فایل APK در **Artifacts** نیز در دسترس خواهد بود.

## ساخت از منبع

نیازمندی‌ها: JDK 17، Android SDK (platform 34 و build-tools 34)

```bash
./gradlew assembleDebug
./gradlew assembleRelease
```

خروجی در مسیر `app/build/outputs/apk/` ساخته می‌شود.

## امضای نسخه انتشار (اختیاری)

برای امضای خودکار در GitHub Actions، این **Secrets** را در مخزن تنظیم کنید:

| Secret | توضیح |
| --- | --- |
| `KEYSTORE_BASE64` | محتوای base64 فایل keystore (`.jks`) با استفاده از `base64 -w0` |
| `KEYSTORE_PASSWORD` | رمز عبور keystore |
| `KEY_ALIAS` | نام کلید |
| `KEY_PASSWORD` | رمز عبور کلید |

افزودن تگ `v1.0.0` باعث آپلود APK به بخش Releases می‌شود.

## به‌روزرسانی محتوای ثبت‌نام‌ها

محتوای برنامه در فایل `docs/registrations.json` نگه‌داری می‌شود. برای افزودن یا اصلاح ثبت‌نام‌ها:

1. فایل `docs/registrations.json` را ویرایش کنید.
2. تغییر را کامیت و پوش کنید.
3. کاربران با زدن دکمه «به‌روزرسانی» در برنامه، جدیدترین محتوا را دریافت می‌کنند.

برنامه برای دریافت این فایل از آینه‌های زیر استفاده می‌کند (در این ترتیب تلاش می‌کند):

1. `raw.githubusercontent.com`
2. `cdn.jsdelivr.net/gh`
3. `USERNAME.github.io/REPO/registrations.json` (GitHub Pages)

در تنظیمات برنامه می‌توانید نشانی JSON دلخواه خود را هم وارد کنید.

## ساختار پروژه

```
app/src/main/
├── assets/           فایل بذر seed_guides.json

│   ├── data/         مخزن و تحلیل محتوا
│   ├── model/        مدل‌های داده
│   ├── ui/            رابط کاربری Compose
│   ├── util/         ابزارها
│   └── viewmodel/     مدیریت وضعیت
└── res/              منابع (فارسی، آیکون‌ها، تم)
docs/
└── registrations.json  منبع به‌روزرسانی در گیت‌هاب
```
